# Curve448 field inversion appendix

This appendix concerns **field** inversion with prime
`p = 2^448 - 2^224 - 1` and exponent `p - 2`. It is separate from the scalar
subgroup `n - 2` results in the main table. The baseline is a source-derived
replay of the [ed448-goldilocks 0.9.0 field inversion implementation](https://docs.rs/ed448-goldilocks/0.9.0/src/ed448_goldilocks/field/mod.rs.html#36-59),
not a new lower chain. The exact source excerpt used in the private assay had
SHA-256 `67b4900bfa847702cd6222129445982dfd22f0297c2e96b9cae75a140d9ca5d5`;
the upstream code itself is not copied here.

| Candidate | Count | Result |
| --- | --- | --- |
| [Source-derived baseline](field/curve448/baseline.json) | 447S + 13M = 460 | Exact exponent and seven nonzero field vectors replayed. |
| Adjacent split `k=223` | 447S + 13M = 460 | Tie. |
| Adjacent split `k=224` | 448S + 14M = 462 | Two operations worse. |

The split grammar and both exact candidates can be regenerated by
[r2/replay.py](field/curve448/r2/replay.py) from the repository root with
`python -B -m field.curve448.r2.replay`. Run the read-only
[field checker](field/curve448/verify_field.py), or run the root
`verify_all.py`, to replay the baseline, both splits, seven field vectors per
candidate, and two invalid-input controls. This checks arithmetic only.

The local R1 run was bounded by 250,000 two-cell proposals and found no lower
candidate; it was iteration-censored, so it did not exhaust its broader
search region. The R2 plan froze `k∈{223,224}` before its 2026-09-28
12:31:55 UTC two-value sweep. Both declared values were exhausted and neither
beat 460. The local R2 receipt was finalized 2026-09-28 12:35:02 UTC.
The original search logs and preregistration files are not part of this
release; these times and search counts are reported provenance, while the
included checker independently replays the three candidate arithmetics.

A [Nettle 4.0 source survey](https://gitlab.com/gnutls/nettle/-/blob/nettle_4.0_release_20260205/ecc-curve448.c#L117-154)
and [Lenngren's 2025 paper](https://eprint.iacr.org/2025/523.pdf) were also
recorded as 447S + 13M comparators. The local Nettle count was replayed from
a source excerpt; the paper's operation table was not independently replayed
in this bundle. No global optimum, native timing, side-channel, or adoption
claim follows from this assay.
