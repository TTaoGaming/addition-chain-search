## Process reconstruction and measurement gaps

The documented representation sequence is: local dictionary/prefix plus exact tail DP (432/429), joint dictionary MILP (426), positive-overlap/carry-aware reverse DP (425), helper and weighted tradeoffs (424), whole-prefix star-chain and insertion mutations (423/422), then fixed-scaffold CPU annealing (421). The source links above show these episodes existed. They do not establish that every step descends by one mutation, that budgets were equal, or that a model learned a transferable search policy. Later target work tested portability and found both arithmetic wins and negative transfer. The [private Gen144 synthesis PR #17](https://github.com/TTaoGaming/hfo-gen-144/pull/17) is a secondary map, not a substitute for the primary receipts.

The release should distinguish candidate generation, exact arithmetic replay, distinct internal verifier, source-level implementation comparison, native benchmark, external adoption, and current-world-best census. Only the earlier rungs have evidence here. Historical CPU wall times apply to the exact reported local probes only. Model calls/tokens, paid-provider spend, comparable CPU-hours, GPU use, operator minutes, and full proposal denominators are UNKNOWN for most episodes; absence of logs is not zero. No native timing, constant-time/security assay, Brian acceptance, or global optimality follows from this ledger.

Privacy boundary: all Gen140/Gen143/Gen144 issue links and Slack links in this file are internal sources. Public history may report sanitized facts with a clear reconstructed/source-held label, but should not expose private repository structure, private Slack links, internal actors, or correspondent messages without a separate release review.
