The table's “Eval matches certificate” and “Direct submit matches” abbreviate these separate fields. The final analysis renamed the earlier provisional broad-copy label; this figure reads only the final pinned keys `evaluations_matching_supplied_retained_schedule` and `direct_submissions_matching_supplied_retained`.
